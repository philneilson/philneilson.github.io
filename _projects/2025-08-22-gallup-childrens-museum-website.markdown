### Project Description

This is a recent web development project. It's a website for Gallup Children's Museum, an organization I volunteer for.  I used Wix to create the site in early 2025. I can take no credit for the amazing graphic design, logos, and color palette; these were developed by Amy Turner of [Turner Studio](https://www.amylturnerstudio.com/)!

This was a fun project, because I was learning the Wix platform as I went along. The museum needed the website to be able to be used to sell museum admission tickets and memberships and allow for donations, and creating each of those functions was a learning experience. The site isn't perfect, but it is the most comprehensive and interactive website I have built so far, and now I feel much more confident in using the Wix platform.
